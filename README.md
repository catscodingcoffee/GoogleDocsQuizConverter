# Google Docs Quiz Converter

Converts the quizzes provided by Cyber.org into Google Forms, but will work for any quiz in the specified format

The format should be
```
1. Question here

A. Option 1

B. Option 2

C. Option 3

D. Option 4

Answer: B
```

## Instructions
1. Open your Google Doc
2. Go to Extensions → Apps Script
3. Paste the code there and save
4. You can run the script from the new menu option Quiz Converter
